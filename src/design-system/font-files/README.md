# Route-scoped fonts

These variable font files are vendored from the official
[`google/fonts`](https://github.com/google/fonts) repository so production
builds do not depend on reaching Google Fonts.

Source revision: `e44c4b011a820c2cbe2fd2cfa8052037d7edb571`

- Cormorant Garamond: `ofl/cormorantgaramond/CormorantGaramond[wght].ttf`
- Noto Serif Lao: `ofl/notoseriflao/NotoSerifLao[wdth,wght].ttf`
- Manrope: `ofl/manrope/Manrope[wght].ttf`
- Space Grotesk: `ofl/spacegrotesk/SpaceGrotesk[wght].ttf`
- JetBrains Mono: `ofl/jetbrainsmono/JetBrainsMono[wght].ttf`

All five families are distributed under the SIL Open Font License 1.1. The
license text is stored beside this file as `OFL.txt`.
